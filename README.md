# coffee.app
自分だけのコーヒー豆の購入記録（ログ）を作成し、蓄積されたデータから自分の好みの傾向を分析・おすすめの豆を提案してくれるWebアプリケーションです。
# サービスの概要
このアプリは、日々のコーヒー体験を記録し、可視化することを目的としています。

コーヒーログ管理: 購入した豆や店舗の名前などの情報、焙煎度・味わい（酸味・苦味・コク・香り）を5段階で詳細に記録。

店舗マップ連携: Google Maps APIと連携し、購入した店舗の場所を地図上で確認。

好み分析・レコメンド:

過去の登録データから、あなたの好みの平均値を算出。

ユークリッド距離を用いたアルゴリズムにより、マスタデータ（17種類の代表的な豆）の中から、あなたの好みに最も近い豆を自動でおすすめします。


# スクリーンショット
# セットアップ方法
1. リポジトリのクローン
   
    リポジトリ内のファイルをダウンロードします
  
2. Google APIキーの設定
   
   メインのPythonファイル内の GOOGLE_API_KEY 変数に、ご自身のGoogle Cloud Platformで発行したAPIキーを入力してください。

    注意: Geocoding API と Maps JavaScript API を有効にする必要があります。
   
    変更必要ファイル

       ・coffee_app.py
       ・upload_coffee_map.html
       ・upload_coffee_input.htm

4. データベースの初期化


   アプリを起動する前に、マスタデータの取得とユーザー用テーブルを作成する必要があります。

   ①まず、豆のマスタデータを取得します。
      
   bean_master.pyを実行し、ブラウザで http://localhost:8782/blist/bean にアクセスして初期化を完了させます。
      
   ②次に、メインアプリの初期設定を行います。
      
   ブラウザで http://localhost:8782/blist/init にアクセスし、ユーザー・店舗・豆管理用のテーブルを作成します。
  
4. アプリケーションの起動
   起動後、 http://localhost:8782/blist/login へアクセスしてください。

# 使い方
1.ログイン・サインイン

http://localhost:8782/blist/loginへアクセスしサインインを行います。
ログインを行います
ホーム画面へ遷移します。

2.記録
ホーム画面から「記録する」をクリックすると記録画面委遷移します
項目に情報を入れた後登録ボタンを押し、登録されたことを確認する

3.登録店舗マップ
ホーム画面から「マップ」をクリック
入力情報をもとにピンがあることを確認します。
ピンをクリックすると、店舗の生rと住所、このお店で購入したコーヒー豆一覧が表示されます。詳細を見るをクリックすると、登録情報を確認できます。

4.傾向分析
ホーム画面から「傾向分析」をクリック
これまで入力した、情報を基に平均評価を表示、それに近い豆が表示される
