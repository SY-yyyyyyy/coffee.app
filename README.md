# 今後の改善案
• マップ画面からの店舗登録機能
現在は記録入力画面からのみ情報を登録可能であるが、今後は地図上をクリックす
ることで店舗情報を登録できる機能を追加する。
• おすすめ機能の改善
現在は事前に登録されたコーヒー豆の情報をもとに分析を行っているが、今後は
ユーザーが保存したコーヒー豆の評価傾向に加え、現在位置周辺の店舗情報を活用
することで、好みに近い豆や店舗を推薦する機能を実装する。
• 画像管理機能の追加
現在は画像URLを保存する方式であるが、将来的には画像ファイルのアップロー
ド機能を追加し、ユーザーがより直感的に記録を振り返れるようにする。
